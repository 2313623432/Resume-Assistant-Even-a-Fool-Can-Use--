Frequently Asked Questions (Private BYOK AI Tailor · 2026)

What does BYOK AI mean for a resume builder?

BYOK stands for Bring Your Own Key: instead of paying a monthly markup to an AI wrapper website, you plug in your own OpenAI, DeepSeek, Google Gemini, or local Ollama API key.

Does ResumeCraft store or log my API key?

No. ResumeCraft has no backend database—your API key is stored solely in your local browser localStorage and only sent directly to the provider endpoint you configure.

Can I run AI tailoring completely offline without paying any API provider?

Yes! Point the custom base URL to a local Ollama instance on your machine for 100% free, offline AI bullet optimization.

Can I still use ResumeCraft without an AI API key?

Absolutely. All resume editing, 8 templates, PDF/DOCX import, vector PDF export, and 1-click HTML website export work 100% without any AI key.
